# Sweet Shop Management System

This project is a Sweet Shop Management System that allows users to manage sweets through a user-friendly web interface.  
It supports user authentication and full CRUD (Create, Read, Update, Delete) operations for sweet items.

The project is built as a frontend application with backend integration for data handling.

---

## Features

- User Registration
- User Login
- Authentication-based protected routes
- View list of sweets
- Add new sweets
- Edit existing sweets
- Delete sweets
- Logout functionality

---

## Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- Axios
- React Router DOM
- CSS

### Backend
- Backend APIs (used for authentication and CRUD operations)
- Spring boot
